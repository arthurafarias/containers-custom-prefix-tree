containers::custom::prefix_tree

A header-only, STL-inspired, thread-safe, std::pmr-aware trie (prefix tree) container mapping std::string keys to values.

  • Ordered, associative container with an STL-like interface: insert, find, erase, at, operator[], iterators sorted by key.
  • Prefix-native queries a hash/tree map can't offer efficiently: starts_with, prefix_range, erase_prefix.
  • Allocator-aware via std::pmr::polymorphic_allocator by default, so node storage can be driven by an arena, pool, or monotonic buffer.
  • Thread-safe: every accessor locks internally, and iterators hold a reference-counted RAII lock for their whole lifetime, so safe iteration doesn't need manual synchronization.
